Kalkulator Keuntungan
Sebuah aplikasi web sederhana untuk menghitung keuntungan dari penjualan barang berdasarkan modal awal, pengeluaran, dan jumlah barang yang dijual. Aplikasi ini juga dilengkapi dengan fitur Refresh untuk mereset semua input dan hasil perhitungan.
Fitur

1. Input Data:

Modal awal (Rp)

Pengeluaran untuk barang (Rp)

Total keuntungan yang diinginkan (Rp)

Jumlah barang yang dijual

2. Perhitungan:

Sisa uang setelah pengeluaran

Total penjualan

Keuntungan per barang

Total uang setelah penjualan

3. Fitur Refresh:

Mereset semua input dan hasil perhitungan ke keadaan awal.
